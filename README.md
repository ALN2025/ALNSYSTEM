# Meu Controle · A.L.N SYSTEM

**Controle financeiro pessoal offline** — credores, despesas, parcelas e módulo fiador. Um único app com plano **Grátis** e **Pro**.

Desenvolvido por **Dev ⩿ A.L.N/⪀**

---

## Destaques

| | |
|---|---|
| **100% offline** | Dados no celular ou PC — sem nuvem obrigatória |
| **Notificações** | Lembretes de vencimento e atraso |
| **Fiador (Pro)** | Acordos, juros e exportação de comprovantes |
| **Privacidade** | [Política pública](https://aln2025.github.io/ALNSYSTEM/privacidade/) (só texto legal, sem download de app) |

---

## Planos

**Grátis:** até 5 credores, 30 despesas, alertas padrão.  
**Pro:** ilimitado, fiador, exportação, mais lembretes de atraso.
